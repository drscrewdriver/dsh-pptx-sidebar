# Журнал изменений

Все заметные изменения этого проекта документируются здесь. Формат основан на
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), а проект следует
[Семантическому версионированию](https://semver.org/spec/v2.0.0.html).

## [0.3.0] — 2026-09-29

### Изменено

- **Линия хоста переведена на DSH 0.2.0** (`main`, повышена из `compat/0.2.0`): `engines.dsh` и
  peer-зависимость `@deepseek-ai/dsh-client-locale` меняются с `>=0.1.5-rc.1 <0.2.0-0` на
  `>=0.2.0-rc.1 <0.2.1-0` (фиксация на rc-окно; 0.2.1+ потребует переоценки). Адаптация только
  метаданных — поверхность потребления плагина состоит из чистых вызовов `ctx.get(...)` с локальными
  определениями интерфейсов, а 0.2.0-rc.1 сохраняет API плагинов 0.1.7 без изменений, поэтому нулевые
  изменения кода. Линии 0.1.x (0.1.5 / 0.1.7) по-прежнему обслуживаются замороженными ветками
  `compat/0.1.7` / `compat/0.1.5` (≤0.2.0).
- Дерево зависимостей обновлено на новую линию; lockfile перегенерирован. `dsh.plugin.json`
  version/engines синхронизированы с `package.json`.

### Документация (2026-09-29 — без повторной публикации)

- Реструктуризация веток: `main` теперь линия 0.2.0 (повышена из `compat/0.2.0`); линии хостов
  0.1.x обслуживаются замороженными ветками `compat/0.1.7` / `compat/0.1.5`.
  Сопоставление npm не изменилось: `dsh-0.2.0` → эта линия, `dsh-0.1.7` / `dsh-0.1.5` → линия 0.1.x.
- Установка (эта линия): `dsh plugin --profile <profile> add dsh-pptx-sidebar@dsh-0.2.0`.
- README получила краткую справку на пяти языках (Deutsch / Français / Русский / Español / Italiano).

## [0.2.0] — 2026-09-23

Адаптация к ширине: режим чтения масштабируется вместе с областью боковой
панели, в определённых пределах.

### Добавлено

- **Широко-адаптивный масштаб** (`src/client/scale.ts` + `useReaderScale.ts`):
  коэффициент, вычисленный из ширины, записывается в пользовательское свойство
  `--reader-scale`, базовый размер шрифта становится `13px × scale`, а
  содержимое слайда выражено в `em`, чтобы следовать за ним. При базовой
  ширине **360 px коэффициент равен ровно 1**, поэтому при обычной ширине
  области вёрстка не меняется; нижняя граница — **0.9**, верхняя — **1.15**.
- **Масштабируется только документ.** Заголовки, маркеры, абзацы, заметки,
  таблицы и подписи к изображениям следуют за коэффициентом; полоса заголовка,
  полоса слайдов, баннер предохранителя и состояния загрузки/пустоты
  сохраняют фиксированный размер. Обрамление интерфейса, меняющее размер при
  перетаскивании разделителя, воспринимается как сбой, а не как отзывчивость.
- **Квантование до двух знаков**, поэтому перетаскивание разделителя
  перевёрстывает содержимое шагами по 0.01, а не на каждом пикселе.
- **Неизмеримые ширины откатываются к 1** — 0, отрицательные значения, NaN
  или Infinity (первый кадр, сбойный отчёт) отображают поставляемую вёрстку,
  а не край диапазона, который заставлял бы крошечный текст вспыхивать при
  открытии.
- **Отступ маркеров в `em`** (`INDENT_EM = 1.08em`) — те же 14 px, что были
  раньше при масштабе 1.
- **Предел ячейки таблицы 320 px → 24.6em**, чтобы ячейки сужались вместе с
  областью вместо появления горизонтальной полосы прокрутки.

### Изменено

- Изображения по-прежнему отображаются в размере, заданном трансформацией
  фигуры, ограниченные только областью: увеличивать растровое изображение
  сверх его естественного размера вслед за масштабом текста значило бы делать
  его более размытым, а не более точным.

### Тесты

- 5 новых проверок (всего 24), покрывающих: коэффициент ровно 1 при базовой
  ширине, обе границы, монотонность, откат при неизмеримой ширине,
  квантование до двух знаков и отступ, соответствующий 14 px при масштабе 1.

### Публикация

- **Первый релиз на npm**: `dsh-pptx-sidebar@0.2.0`, dist-теги `latest` +
  `dsh-0.1.5`; 39 файлов / 83.1 kB, shasum тарболла
  `e6faf24a4e1c8e32a561ecb8693c828759626e96`.
- Опубликованный пакет декларирует **`repository`**, указывающий обратно на
  `drscrewdriver/dsh-pptx-sidebar`. Awesome-список связывает npm-пакет с
  репозиторием только тогда, когда опубликованный пакет указывает на него.

## [0.1.0] — 2026-09-22

Первый релиз. Читает `.pptx` / `.pptm` как структурированный режим чтения в
правой боковой панели DSH.

### Добавлено

- Регистрация просмотрщика файлов для `.pptx` и `.pptm` (`priority: 50`,
  `fetchStrategy: 'custom'`); байты получаются через маршрут `/sidebar/file`
  better-sidebar, так что ограждение путей рабочего пространства остаётся на
  стороне хоста.
- Список слайдов, порядок которого приходит **только** из `p:sldIdLst`,
  разрешаемого через связи презентации, — никогда из сортировки имён файлов
  частей. Абсолютные и относительные (`../`) цели связей разрешаются оба
  варианта; цели External игнорируются.
- Обход дерева фигур (`p:sp`, `p:pic`, `p:graphicFrame`, `p:grpSp`) с одним
  счётчиком глубины, благодаря которому сгруппированные фигуры отдают свой
  текст ровно один раз.
- Извлечение текста с уровнями маркеров по абзацам (`a:pPr@lvl`, 0-based →
  1-based) и полужирными/курсивными фрагментами.
- Определение заголовка по **типу** заполнителя (`title` / `ctrTitle`), а не
  по позиции или размеру шрифта.
- Заметки докладчика из частей `notesSlide` с пропуском заполнителя-изображения
  слайда. Слайд без заметок не даёт ни блока, ни предупреждения, ни ошибки.
- Встроенные изображения: `a:blip@r:embed` → связь → байты архива → blob URL,
  с пересчётом размеров EMU→px. Неотрисовываемые форматы (EMF/WMF) становятся
  подписанными заполнителями вместо молчаливых пробелов.
- Настоящие таблицы из графических фреймов `a:tbl`.
- Семь предохранителей (архив / суммарная инфляция / отдельная часть / слайды /
  текст слайда / изображения / отдельное изображение), с **одним
  предупреждением на измерение**.
- Словари zh и en, включая шаблон для каждой причины срабатывания
  предохранителя.
- Сборка с настоящим загрузочным барьером: клиентский бандл вычисляется в
  песочнице `node:vm`, а экспорт фабрики проверяется на наличие `apply` и
  `inject`.
- `npm test` — 19 проверок против враждебной фикстуры, собранной в самом
  процессе.
- Скрипты публикации и миграции профиля (по умолчанию `-DryRun`), включая
  preflight, отклоняющий спецификацию, которая ещё не разрешается.

### Сознательно не включено

- Наследование заполнителей из макетов и образцов: v1 читает только
  собственную часть слайда. Обоснование — в одноимённом разделе README.
- Точность визуальной вёрстки, шрифты темы, анимация, редактирование,
  поддержка `.ppt`.
